SAÚDE NA HORA — INSTRUÇÕES

1. Extraia o arquivo ZIP para uma pasta.
2. Abra o arquivo index.html em um navegador atualizado.
3. Clique em "Criar conta", preencha os dados e faça o cadastro.
4. Depois do cadastro, o sistema abre automaticamente.
5. Em "Agendar consulta", escolha profissional, data e horário.
6. Para testar conflitos, abra outro navegador/perfil ou crie outra conta e tente reservar o mesmo profissional, data e horário.
7. Para testar a fila:
   - reserve um horário com uma conta;
   - entre com outra conta e tente reservar o mesmo horário;
   - aceite entrar na fila;
   - cancele a primeira consulta. O primeiro paciente da fila será promovido automaticamente.
8. Em "Operações", é possível ver a pilha e desfazer a última operação.

TECNOLOGIAS
- HTML
- CSS
- JavaScript
- localStorage

CONTEÚDOS DE JAVASCRIPT
- Arrays: pacientes, profissionais, consultas, filas, histórico e pilha.
- Matriz: organização de profissionais por horários.
- Fila (FIFO): promoção do primeiro paciente que aguardava o horário.
- Pilha (LIFO): registro das operações recentes e opção de desfazer.
- Laços e métodos de repetição: percorrer e filtrar consultas/horários.
- localStorage: persistência dos dados no navegador.

IMPORTANTE
- Os dados ficam salvos apenas no navegador/dispositivo utilizado.
- Este é um projeto escolar demonstrativo. Não use dados reais de pacientes.
- As senhas ficam em texto no localStorage; isso não é seguro para produção.
- Os profissionais e horários são exemplos fixos, conforme a proposta simplificada.
